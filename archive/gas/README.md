# Wiki付与 行作業 — Google Apps Script

Next.js 版（リポジトリ直下 `src/`）と同じスプレッドシートを使う GAS 版（予備・退避）。  
設計仕様は **[SPEC.md](./SPEC.md)** を参照。

## セットアップ

1. スプレッドシートを開く
2. **拡張機能 → Apps Script**
3. `gas/` 内のファイルを同名で追加（`Sidebar.html` は **WorkApp.html** に置き換え）
4. `Config.gs` の `SPREADSHEET_ID` が対象シートの ID か確認
5. 保存

---

## 2-A. サイドバーで試す（デプロイ不要）

1. スプレッドシートを再読み込み
2. **Wiki付与作業 → 作業サイドバーを開く**
3. 初回のみ権限承認

---

## 2-B. Web アプリ URL で試す（推奨・全画面）

### デプロイ手順

1. Apps Script エディタ → **デプロイ → 新しいデプロイ**
2. 歯車 → 種類 **ウェブアプリ**
3. 設定:

| 項目 | 値 |
|------|-----|
| **次のユーザーとして実行** | **アクセスしているユーザー** |
| **アクセスできるユーザー** | **組織内** または **Google アカウントを持つ全員** |

4. **デプロイ** → 表示された **URL** をコピー（`/exec` で終わる方）
5. ブラウザで URL を開く → 初回のみ Google ログイン・権限承認

### 共有

- スプレッドシートの **編集権限** を付与
- Web アプリ URL を共有
- 各自が初回だけ「許可」

### コード更新後

**デプロイ → デプロイを管理 → 鉛筆 → 新バージョン → デプロイ**（Web アプリ必須）

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `Code.gs` | `doGet`（Webアプリ）・サイドバー・メニュー |
| `WorkApp.html` | UI（サイドバー / Web アプリ共用） |
| `Config.gs` | 定数・`SPREADSHEET_ID` |
| `SheetService.gs` | 読み書き API |
| `WorkColumns.gs` / `Utils.gs` | 列ルール（app.py 移植） |

## 書き込み OFF

`Config.gs` の `ENABLE_SHEET_WRITES: false`

## トラブルシュート

| 症状 | 対処 |
|------|------|
| Web アプリが真っ白 / エラー | `SPREADSHEET_ID`・シート編集権限を確認 |
| 権限ダイアログ | 「詳細」→「（安全ではないページ）に移動」→ 許可 |
| 古い UI | デプロイを **新バージョン** で再デプロイ |
| 列がおかしい | 「キャッシュクリア」→「キュー再読込」 |
